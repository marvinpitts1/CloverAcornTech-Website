# Clover Acorn Technologies — Turquoise & Sunshine edition

Six **standalone** HTML pages. Each HTML file contains its own CSS and JavaScript, so no assets folder is required. All pages link to each other using relative paths.

## Publish
1. Extract this ZIP.
2. Upload the six `.html` files into the **root** of the `marvinpitts1/CloverAcornTech-Website` GitHub repository.
3. In GitHub Settings → Pages, deploy from `main` branch, `/ (root)`.
4. Only after reviewing content and enabling Pages, connect `clover-acorntech.com` using GitHub's custom domain settings and Squarespace DNS.

## Before going live
- Photos are loaded remotely from Unsplash and need internet access. Check usage rights and replace with owned/licensed images if desired.
- Contact form is a visual preview and **does not send messages**. Configure a verified email and form delivery service.
- Privacy and Terms pages are included. Confirm that their statements match actual website practices and obtain legal review as appropriate before publishing.
- Scholarship Finder and HolistIQ Health links are external.
- No workforce project references are included.
